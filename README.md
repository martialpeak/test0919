# فیلم بره - MovieBrowser (React Web Application)

یک وب‌اپلیکیشن جامع و پیشرفته برای مرور، جستجو، تماشای تریلر و پیگیری سریال‌ها و فیلم‌های ایرانی و بین‌المللی با تم تاریک سینمایی.

## 🎬 امکانات اصلی

- 🎞️ **آرشیو جامع و دسته‌بندی‌شده**: دسته‌بندی‌های سریال، سریال ترکی، سریال ایرانی، سریال خارجی، فیلم ایرانی، فیلم هندی، فیلم خارجی و کودک
- 🔍 **جستجوی آنی و فیلترهای پیشرفته**: جستجو بر اساس عنوان فارسی، انگلیسی، نام بازیگران، ژانر، کشور و توضیحات
- 🌟 **نمای شبکه‌ای و سطری**: جابجایی بین حالت‌های Grid و List با مرتب‌سازی بر اساس جدیدترین، سال تولید، امتیاز و نام
- 🏆 **باکس آفیس جهانی (Box Office)**: رتبه‌بندی پرفروش‌ترین فیلم‌های تاریخ سینما همراه با مدال‌های طلا، نقره و برنز
- 📺 **پیگیری تماشا (Watchlist & Progress)**: سیستم پیشرفته پیگیری قسمت‌های سریال‌ها (مانند Trakt)، دفعات تماشا، تاریخ پخش اپیزود بعدی و یادداشت‌های شخصی
- 🎬 **پخش تریلر اختصاصی**: پخش‌کننده ویدیو و تریلر با پشتیبانی از فرمت‌های MP4، یوتیوب و لینک‌های IMDb
- 👥 **اطلاعات کامل عوامل و بازیگران**: نمایش مشخصات کارگردان‌ها، نویسندگان و بازیگران به همراه بیوگرافی ترجمه‌شده و تصاویر
- ❤️ **علاقه‌مندی‌ها (Favorites)**: نشانه‌گذاری فیلم‌های محبوب و فیلتر سریع
- 💾 **ذخیره‌سازی هوشمند و حالت آفلاین**: کش محلی و قابلیت همگام‌سازی آنلاین با سرور
- ⚙️ **تنظیمات و مدیریت حافظه**: بررسی وضعیت اتصال، آمار فیلم‌ها و امکان بازنشانی داده‌ها

## 🛠️ فناوری‌ها

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** (طراحی اختصاصی تم تاریک سینمایی و راست‌چین RTL)
- **Lucide Icons**
